{% trans %}This document has the goal to:{% endtrans %}

  • {% trans %}Make it possible for anyone to use the Mixxx name or logo for community-oriented efforts that help spread and improve Mixxx.{% endtrans %}
  • {% trans %}Make it clear how Mixxx-related businesses and projects can (and cannot) use the Mixxx name and logo.{% endtrans %}
  • {% trans %}Ensure that users know which versions of Mixxx are official and supported by the Mixxx organizations.{% endtrans %}
  • {% trans %}Make it hard for anyone to use the Mixxx name and logo to unfairly profit from, trick or confuse people who are looking for official Mixxx resources.{% endtrans %}

{% trans %}Mixxx Trademark Usage Policy{% endtrans %}

{% trans %}Provided your use is truthful, non-misleading, and complies with honest commercial practices, you may do the following without receiving specific permission from Mixxx e.V.:{% endtrans %}

  • {% trans %}Use the Mixxx wordmark (the “Mixxx” name) in text to truthfully refer to and/or link to the unmodified Mixxx software (signed executable), products, services and technologies published by Mixxx e.V.{% endtrans %}
  • {% trans %}Use Mixxx logos in visuals to truthfully refer to and/or to link to the applicable programs, products, services and technologies hosted under the Mixxx.org domain or operated by Mixxx e.V..{% endtrans %}
  • {% trans %}Create and distribute packages and builds of Mixxx from the source code of a released version published at https://github.com/mixxxdj/mixxx/releases under the following conditions:{% endtrans %}
    • {% trans %}The distribution does not enable additional features that are not enabled by default in the CMakelists.txt of the release.{% endtrans %}
    • {% trans %}The distribution does not disable features that are enabled by default in the CMakelists.txt of the release.{% endtrans %}
    • {% trans %}The distribution uses only dependencies/libraries in the version range that is supported in the CMakelists.txt of the release.{% endtrans %}
    • {% trans %}The source code is unmodified/unpatched, except for changes technically necessary to support the target platform.{% endtrans %}
  • {% trans %}Create and distribute a controller mapping configuration or custom skin for Mixxx without suggesting that it is published by, affiliated with, or endorsed by Mixxx.{% endtrans %}
  • {% trans %}Use the Mixxx wordmark in a descriptive way to explain that your software is based on Mixxx’s open source code, or is compatible with Mixxx’s software.{% endtrans %}
  • {% trans %}Create a social media account, page, or community pertaining to Mixxx, provided that their name or handle does not begin with “Mixxx”. In addition, Mixxx logos cannot be used in a way that might suggest direct affiliation with or operation by Mixxx, including, but not limited to, the account, profile, or header images.{% endtrans %}

{% trans %}All other uses of the Mixxx trademark require our prior written permission. But Mixxx e.V. is always open to discuss collaborations and individual permissions, please contact ev@mixxx.org to discuss special permissions. Please refrain from the following without working with us first:{% endtrans %}

  • {% trans %}Don’t use the Mixxx trademark in the name of your business, product, service, app, domain name, publication, or other offering. {% endtrans %}
  • {% trans %}Don’t use marks, logos, company names, slogans, domain names, or designs that are confusingly similar to Mixxx trademarks.{% endtrans %}
  • {% trans %}Don’t use the Mixxx trademark in a way that incorrectly implies affiliation with, or sponsorship, endorsement, or approval by Mixxx e.V. of your products or services. {% endtrans %}
  • {% trans %}Don’t display the Mixxx trademark more prominently than your product, service, or company name.{% endtrans %}
  • {% trans %}Don’t use the Mixxx trademark on merchandise for sale (e.g., selling t-shirts, mugs, etc.){% endtrans %}
  • {% trans %}Don’t use the Mixxx trademark for any other form of commercial use (e.g. offering technical support services), unless such use is limited to a truthful and descriptive reference (e.g. “Independent technical support for Mixxx”). {% endtrans %}
  • {% trans %}Don’t modify engage in the above behavior with an alteration or abbreviation or alteration of Mixxx’s trademark.{% endtrans %}

{% trans %}Please note that it is not the goal of this policy to limit commercial activity around Mixxx. We are excited to see all of the innovation happening around Mixxx and want to provide a clear path for creators looking to experiment in this way.{% endtrans %}
